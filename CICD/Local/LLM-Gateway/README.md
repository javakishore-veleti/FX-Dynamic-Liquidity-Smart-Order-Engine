# fx-llm-gateway (LiteLLM Proxy)

Language-agnostic OpenAI-compatible LLM router for Spring AI and Python LangGraph.

```bash
npm run local:llm-gateway:start
npm run local:llm-gateway:status
npm run local:llm-gateway:stop
```

- URL: http://localhost:4000
- Key: `sk-local-fx-sor` (override with `LITELLM_MASTER_KEY`)
- Models: `fx-reasoning-tier`, `fx-fast-triage-tier`, `fx-graph-tier`, `fx-embedding-tier`
